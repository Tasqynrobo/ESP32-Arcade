# OLED Pixel Runner

A small platformer game made with ESP32, SSD1306 OLED display, and push buttons.

## Features
- Double jump
- Obstacles
- Coins and score system
- Power-ups
- Lives/HP system
- Increasing difficulty over time

## Hardware
- ESP32
- 0.96" OLED Display (SSD1306)
- Push buttons
- Breadboard

## Controls
- Left button → Move left
- Right button → Move right
- Jump button → Jump / Double jump
